# 箸にも棒にもかからない

割り箸を長押しで割る、スマートフォン向けの短いブラウザゲーム。失敗するほど使えない箸が積もり、無表情の店員の視線が気になってきます。

## 起動
`index.html` をブラウザで開くだけで遊べます。インストール、ビルド、外部サーバー、ログインは不要です。スマートフォンにはフォルダーを静的ホスティングへ配置するか、ローカルHTTP配信してアクセスしてください。

## 操作
タイトルをタップ。ボタンを長押しし、指を離して割ります。PCはマウス、またはボタンにフォーカスしてスペース／Enterを長押し。ゲージは約1.45秒で片道、一定速度で往復します。箸がふっと外側へしなる瞬間を手がかりにしてください。成功位置は毎膳変わり、成功ゾーンは表示されません。操作キャンセルや画面の非表示で力をリセットします。

## 技術と構成
HTML / CSS / JavaScript、SVGイラスト、Web Audio API、対応端末のみVibration APIを使用。

- `index.html`：タイトル、ゲーム、結果
- `css/style.css`：スマートフォン優先のレスポンシブ表示
- `js/game.js`：状態管理、判定、6種類の裂け方、箸の山、視線、効果音
- `assets/images/meal.svg`：定食イラスト。その他はCSSとSVGで描画
- `assets/audio/`：音の実装メモ

成功中心は18〜82、初期の許容幅は±5。5回目の失敗後から1.8ずつ拡大し最大±48。中央を固定で狙っても成功しにくいよう広い範囲で中心をランダム化。成功位置付近で箸が外側へしなる視覚的な手がかりがあり、ゲージ上に成功ゾーンは表示しません。操作キャンセルでは同じ箸の成功位置を保持します。全失敗数を保持し、山は最大60個のSVGで描画を制限します。申し訳なさは `100 × (1 − exp(−(失敗数 / 8)²))`（四捨五入、上限100％）。

素材の交換箇所は `wood()`、店員のCSS、`meal.svg`、`noise()`。定食画像の読み込みが失敗しても操作は続きます。音・振動の失敗は捕捉します。

## 検証
Node.js がある環境では node tests/game.test.cjs でロジックを検証できます。成功・失敗、二重解放、80回連続失敗、6種類の形状、視線、救済、キャンセル、オチ、申し訳なさ、再プレイ、音・振動非対応の検証を通過。実ブラウザでのスマートフォン表示・タッチ・音響の確認は未実施です。

店員の演出：最初は不在。失敗箸3膳で約3.2秒かけて机の向こう側へ歩き、11膳で約2.4秒かけて机のこちら側へ迫り、無表情のままプレイヤーを見続けます。再プレイすると退場・歩行タイマーも初期化します。2膳では不在、3膳で歩行開始、到着後の視線維持、歩行中の初期化を自動テストで確認済みです。
